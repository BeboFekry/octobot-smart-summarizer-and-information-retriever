# Octobot
Octobot is an AI based smart summarizer and information retriever.

---
### Key Features:
1. Support text and voice interaction for faster communication (Arabic & English)    
2. Suuport texxt files attachment [pdf, txt, docx] resiurces
3. Suuport web scrapping to access web articles resources
4. Support Youtube video subtitles scrapping resources
5. Answers from only the attached data resources with references
6. Conversational multi chat memory managed in each session
